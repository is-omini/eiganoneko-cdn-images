# 🖼️ eiganoneko-cdn-images

Dépôt CDN d'images utilisé par **[Eiga No Neko](https://eiganoneko.com/)** et d'autres sites compatibles pour afficher des visuels dans leurs catalogues d'animés et de médias japonais.

```

```

---

## ✅ Conditions d'utilisation

- ✅ Les images de ce dépôt sont **librement utilisables** pour tout projet souhaitant afficher des informations sur les œuvres référencées.
- ✅ L'utilisation dans des catalogues, sites de présentation ou applications est autorisée.
- ⚠️ Les images provenant de tiers (studios, distributeurs…) restent soumises à leurs droits respectifs.
- ❌ Toute utilisation commerciale ou redistribution sans mention de la source est déconseillée.

---

## 🤝 Contribuer

Tu souhaites ajouter ou corriger des images ?

1. Fork le dépôt
2. Ajoute tes images dans le dossier correspondant
3. Ouvre une Pull Request en décrivant les ajouts

Merci de respecter les conventions de nommage déjà en place dans chaque dossier.
