# 🖼️ eiganoneko-cdn-images

Dépôt CDN d'images utilisé par **[Eiga No Neko](https://github.com/is-omini)** et d'autres sites compatibles pour afficher des visuels dans leurs catalogues d'animés et de médias japonais.

---

## 📌 À propos

Ce dépôt sert de source d'images centralisée (CDN). Les images qu'il contient sont **activement utilisées** pour enrichir l'affichage des fiches du catalogue d'Eiga No Neko : affiches, personnages, staff, acteurs vocaux, miniatures, vidéos et images hero.

Tout site ou projet souhaitant afficher ces visuels peut pointer directement vers les fichiers de ce dépôt via les URLs raw de GitHub.

---

## 📁 Structure du dépôt

```
eiganoneko-cdn-images/
├── characters/      # Illustrations et visuels des personnages
├── hero/            # Images bannière / hero pour les fiches
├── poster/          # Affiches officielles des œuvres
├── staff/           # Photos ou visuels du staff (réalisateurs, scénaristes…)
├── thumbnail/       # Miniatures pour les listes et aperçus
├── video/           # Vignettes ou captures liées aux vidéos
└── voice-actors/    # Photos ou visuels des doubleurs / seiyū
```

---

## 🔗 Utilisation

Les images sont accessibles via l'URL raw de GitHub :

```
https://raw.githubusercontent.com/is-omini/eiganoneko-cdn-images/main/{dossier}/{fichier}
```

**Exemples :**

```
https://raw.githubusercontent.com/is-omini/eiganoneko-cdn-images/main/poster/exemple.jpg
https://raw.githubusercontent.com/is-omini/eiganoneko-cdn-images/main/characters/exemple.png
https://raw.githubusercontent.com/is-omini/eiganoneko-cdn-images/main/voice-actors/exemple.jpg
```
